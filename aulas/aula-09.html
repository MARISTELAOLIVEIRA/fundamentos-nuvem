C · conceitos

A rede como um condomínio

C1

Rede virtual e sub-redes

Quando você coloca um sistema na nuvem, ele mora dentro de uma rede virtual: um pedaço isolado da rede do provedor, só seu. Dentro dela, você divide o espaço em sub-redes.

C2

Os mesmos conceitos com os nomes de cada nuvem

ConceitoAWSAzureGoogle Cloud
Rede virtualAmazon VPCAzure Virtual Network (VNet)VPC
Sub-redeSub-rede (fica numa zona)Sub-redeSub-rede (fica numa região)
Porteiro (firewall)Grupos de segurançaGrupos de segurança de rede (NSG)Regras de firewall da VPC
Atalho até o cliente (CDN)Amazon CloudFrontAzure Front DoorCloud CDN
Nomes de domínio (DNS)Amazon Route 53Azure DNSCloud DNS

Na AWS, a VPC fica numa região, e cada sub-rede fica numa zona de disponibilidade. Para a loja ficar no ar se uma zona cair, você cria sub-redes em duas zonas.

No Azure, a VNet fica numa região. O porteiro é o NSG, que você associa a uma sub-rede ou a uma máquina. Quem vem do mundo Microsoft (Windows Server, Active Directory) se sente em casa.

No Google Cloud, a grande diferença: a VPC é global. Uma mesma rede pode ter sub-redes em regiões diferentes do mundo, conversando entre si sem configuração extra.

P · prática interativa

Agora é a sua vez

Errou? Ótimo: é errando aqui que você acerta na avaliação. Cada resposta traz a explicação.

Classifique! Público ou privado?

  1. O site da loja.
  2. O banco de dados com os pedidos e os clientes.
  3. O balanceador de carga que recebe os acessos.
  4. O servidor que gera as notas fiscais à noite.
Verdade ou mito?

  1. No Google Cloud, uma VPC pode ter sub-redes em regiões diferentes.
  2. Colocar o banco de dados na sub-rede pública deixa o site mais seguro.
  3. Uma CDN guarda cópias do conteúdo perto do cliente para o site carregar mais rápido.
  4. Azure VNet, Amazon VPC e Google VPC são o mesmo conceito com nomes diferentes.

As fotos dos doces carregam devagar para um cliente em Manaus. O que ajuda?

  • Uma senha mais forte.
  • Uma CDN (CloudFront, Azure Front Door ou Cloud CDN).
  • Um firewall mais rígido.
  • Mudar o banco para a sub-rede pública.
EC · estudo de caso

A rede do Ateliê

O site do Ateliê precisa ser visto por todo mundo, mas o banco de dados com os pedidos não pode ficar exposto na internet.

Para pensar (e desenhar)

  1. Desenhe no papel um retângulo grande (a rede virtual) com dois menores dentro: a sub-rede pública e a privada.
  2. O que vai em cada uma? Como o site conversa com o banco, se o banco não está na internet?
  3. Que regra o porteiro (firewall) do banco deve ter? (Dica: só aceitar conversa vinda do site.)
