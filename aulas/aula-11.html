C3

Backup: a regra do "não tudo num lugar só"

Uma regra famosa é a 3-2-1: 3 cópias dos dados, em 2 tipos de armazenamento diferentes, com 1 cópia fora do lugar principal. Na nuvem, dá para guardar cópias em outra zona ou até em outra região, automaticamente.

P · prática interativa

Agora é a sua vez

Errou? Ótimo: é errando aqui que você acerta na avaliação. Cada resposta traz a explicação.

Classifique! Que tipo de armazenamento?

  1. As fotos dos doces que aparecem no site.
  2. O disco onde está instalado o sistema da máquina virtual.
  3. As planilhas que a equipe abre e edita ao mesmo tempo.
  4. Os backups diários da loja.
  5. O disco rápido usado pelo banco de dados numa VM.

Qual é o armazenamento de objetos do Google Cloud?

  • Cloud SQL
  • Persistent Disk
  • Filestore
  • Cloud Storage
Verdade ou mito?

  1. Notas fiscais que precisam ser guardadas por anos, mas quase nunca são abertas, combinam com a classe de arquivo.
  2. O Amazon EBS é usado para guardar as fotos do site com endereço público.
EC · estudo de caso

Onde guardar cada coisa no Ateliê?

O Ateliê tem: as fotos dos doces do site, as notas fiscais (que precisam ser guardadas por anos), o disco do servidor da loja e as planilhas que a equipe usa junta.

Para pensar

  1. Que tipo de armazenamento serve para cada um? Escolha uma nuvem e use os nomes dela.
  2. O que dá para guardar numa classe mais barata?
  3. Como ficaria o backup, sem o HD externo da Dona Lu? Aplique a regra 3-2-1.
