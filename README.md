## `$ aws configure get region`

Prazer, eu sou a **Profa. Maristela**, ou só **Stela**! 👋

Boas-vindas à **Fundamentos de Computação em Nuvem**, do curso de **Análise e Desenvolvimento de Sistemas** da
Faculdade de Tecnologia e Inovação Senac DF (60 horas, a distância).

Este repositório é o **site da disciplina**: o lugar onde ficam as aulas, os estudos de caso e os materiais. Nada de
slides: aqui a aula é o próprio site.

A nuvem não é mágica: é o computador de outra pessoa, alugado na hora certa. Neste semestre a gente entende o que
ela é, faz as contas de quanto custa, escolhe os serviços e desenha a arquitetura de uma pequena empresa (fictícia)
que decide sair da sala de servidores.

## O que tem aqui

- **18 aulas**, cada uma com o conteúdo, um estudo de caso, um checklist e o módulo da AWS Academy e do Microsoft
  Learn que vai junto.
- **AWS Academy Cloud Foundations**, a trilha principal, e as três trilhas do **AZ-900** no Microsoft Learn, para ver
  como é no Azure.
- Ferramentas gratuitas, sem cartão de crédito: AWS Pricing Calculator, calculadora de preços do Azure e draw.io.
