C3

Os nomes em cada nuvem

TipoAWSAzureGoogle Cloud
Relacional gerenciado (MySQL, PostgreSQL...)Amazon RDS (e Amazon Aurora)Banco de Dados do Azure para MySQL/PostgreSQL e Azure SQL DatabaseCloud SQL (e AlloyDB)
Não relacional gerenciadoAmazon DynamoDBAzure Cosmos DBFirestore e Bigtable

Na AWS, o Amazon RDS gerencia MySQL, PostgreSQL, SQL Server e outros. O DynamoDB é o NoSQL da casa, famoso por aguentar tráfego gigante.

No Azure, o Azure SQL Database é o SQL Server gerenciado (o queridinho das empresas que já usam Microsoft). O Cosmos DB é o NoSQL, com distribuição global.

No Google Cloud, o Cloud SQL gerencia MySQL, PostgreSQL e SQL Server. Para NoSQL, o Firestore é muito usado em aplicativos, e o Bigtable em volumes enormes.

Classifique! Relacional ou não relacional?

  1. Cadastro de clientes, pedidos e itens de cada pedido.
  2. O carrinho de compras, que muda a cada clique.
  3. O controle financeiro da loja, com débitos e créditos.
  4. As preferências de cada cliente no aplicativo (cada um com campos diferentes).

Qual é o banco não relacional (NoSQL) do Azure?

  • Azure Files
  • Azure Cosmos DB
  • Azure SQL Database
  • Azure Functions
Verdade ou mito?

  1. Num banco gerenciado, o provedor decide quem pode acessar os dados da empresa.
  2. O Cloud SQL do Google pode rodar MySQL e PostgreSQL.
