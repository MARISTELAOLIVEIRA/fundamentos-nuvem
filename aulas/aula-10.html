P · prática interativa

Agora é a sua vez

Errou? Ótimo: é errando aqui que você acerta na avaliação. Cada resposta traz a explicação.

Classifique! Qual jeito de rodar?

  1. Um sistema antigo de estoque que só roda numa versão específica do Windows.
  2. Enviar um e-mail de confirmação a cada pedido.
  3. O site da loja, dividido em partes (vitrine, carrinho, pagamento), que precisa subir rápido.
  4. Gerar uma miniatura toda vez que uma foto de doce é enviada.
  5. Um servidor de jogos que precisa de um sistema operacional configurado à mão.

Qual é a função sem servidor do Azure?

  • Azure Functions
  • Azure Virtual Machines
  • Azure Container Apps
  • AKS

No Google Cloud, qual serviço roda contêineres sem você gerenciar servidores?

  • Compute Engine
  • Cloud Run
  • Cloud SQL
  • Cloud CDN
EC · estudo de caso

Três tarefas, três serviços?

O Ateliê tem três tarefas: o site da loja, que fica no ar o tempo todo; um sistema antigo de estoque, que só roda em Windows; e o e-mail de confirmação a cada pedido.

Para pensar

  1. Qual serviço de computação você usaria para cada tarefa? Escolha uma nuvem e use os nomes dela.
  2. Qual das três tarefas fica mais barata com uma função sem servidor? Por quê?
  3. O que a Dona Lu (ou o sobrinho) precisa gerenciar em cada escolha?
