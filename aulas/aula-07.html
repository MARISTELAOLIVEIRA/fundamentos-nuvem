P · prática interativa

Agora é a sua vez

Errou? Ótimo: é errando aqui que você acerta na avaliação. Cada resposta traz a explicação.

Classifique! Provedor ou cliente?

  1. A segurança física do data center.
  2. Criar senhas fortes e ativar MFA nas contas.
  3. Trocar um disco com defeito num servidor físico.
  4. Decidir quem pode ver os dados dos clientes.
  5. Manter o hipervisor atualizado.
  6. Atualizar o sistema operacional de uma máquina virtual (IaaS).
Verdade ou mito?

  1. Uma zona de disponibilidade é a mesma coisa que uma região.
  2. Colocar o sistema em duas zonas ajuda a mantê-lo no ar se uma zona falhar.
  3. No SaaS, o cliente não tem nenhuma responsabilidade de segurança.
EC · estudo de caso

Os dados dos clientes podem ir para os Estados Unidos?

O Ateliê guarda nome, endereço e telefone dos clientes para as entregas. Um amigo da Dona Lu disse que fica mais barato guardar tudo nos Estados Unidos. Ela quer saber se pode, e quem responde se os dados vazarem.

Para pensar

  1. Qual região você escolheria para os dados dos clientes? Use os quatro critérios do conceito C2.
  2. O que a LGPD tem a ver com essa escolha?
  3. Se os dados vazarem por causa de uma senha fraca, de quem é a responsabilidade?

A LGPD (Lei 13.709/2018) não proíbe guardar dados fora do Brasil, mas exige cuidados específicos para essa transferência internacional. Por isso, para uma empresa pequena, a região de São Paulo costuma ser o caminho mais simples.
